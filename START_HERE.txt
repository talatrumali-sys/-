تحدّي التوقعات — بناء تطبيق أندرويد (APK) بدون أي برمجة
=========================================================
كل شيء يتم من المتصفح فقط. المدة الكلية حوالي 20 دقيقة. الخدمتان مجانيتان.
هذه النسخة تُنتج APK موقّعًا بمفتاح Debug تلقائيًا؛ لا يوجد ملف توقيع سري داخل المشروع.

الجزء الأول: قاعدة البيانات (Supabase)
--------------------------------------
1) افتح supabase.com واضغط Start your project، ثم أنشئ حسابًا (يمكنك الدخول بحساب GitHub أو Google).
2) اضغط New project. اكتب أي اسم (مثل roma) وأي كلمة مرور لقاعدة البيانات واحفظها،
   واختر أقرب منطقة، ثم اضغط Create new project وانتظر دقيقة أو دقيقتين.
3) من القائمة اليسرى اختر SQL Editor ثم New query.
   افتح ملف supabase-setup.sql من هذا المجلد بالمفكرة، انسخ كل محتواه والصقه، ثم اضغط Run.
   (إذا سألك عن تأكيد، اضغط Run this query). يجب أن تظهر رسالة Success.
4) من الإعدادات (Project Settings) ثم API، انسخ قيمتين واحفظهما:
   - Project URL  (يبدأ بـ https:// وينتهي بـ supabase.co)
   - المفتاح العام: anon public  (أو Publishable key)

الجزء الثاني: بناء الـ APK (GitHub)
-----------------------------------
5) افتح github.com وأنشئ حسابًا مجانيًا، ثم اضغط New repository.
   اكتب اسمًا (مثل roma-app)، واختر Private (موصى به لحماية ملفات المشروع)، ثم Create repository.
6) في صفحة المستودع اضغط "uploading an existing file".
   فك ضغط هذا الملف على جهازك، ثم اسحب كل ما بداخله إلى الصفحة (الملفات والمجلدات كلها،
   بما فيها المجلد المخفي .github). انتظر انتهاء الرفع ثم اضغط Commit changes.
   * إذا لم يظهر المجلد .github بعد الرفع: اضغط Add file ثم Create new file،
     واكتب في الاسم:  .github/workflows/build.yml
     والصق محتوى الملف build.yml.txt ثم Commit.
7) افتح مجلد www ثم الملف config.js واضغط على أيقونة القلم ✏️.
   ضع الرابط بدل: ضع_هنا_رابط_المشروع   وضع المفتاح بدل: ضع_هنا_المفتاح_العام
   (احتفظ بعلامتي الاقتباس) ثم اضغط Commit changes. هذا يبدأ البناء تلقائيًا.
8) اضغط تبويب Actions وانتظر نحو 6 إلى 10 دقائق حتى تظهر علامة ✅ خضراء.
   ثم افتح تبويب Actions، ادخل إلى آخر عملية ناجحة، ومن Artifacts حمّل Tahaddi-Altawaqqoat-APK.zip ثم فك ضغطه لتحصل على Tahaddi-Altawaqqoat.apk. وقد يظهر أيضًا في Releases إذا اكتمل نشر الإصدار.

الجزء الثالث: التشغيل
---------------------
9) ثبّت الـ APK على هاتفك (اسمح بالتثبيت من مصدر غير معروف عند السؤال).
   افتح التطبيق وأنشئ حسابك أولًا قبل أي صديق: أول حساب يُنشأ يصبح المدير تلقائيًا.
10) أرسل لأصدقائك عبر واتساب هذا الرابط المباشر (غيّر الاسمين):
    https://github.com/اسم-حسابك/اسم-المستودع/releases/latest/download/Tahaddi-Altawaqqoat.apk
    كل صديق ينشئ حسابه من داخل التطبيق.

مهم: لأن البناء يستخدم توقيع Debug تلقائيًا، قد يتطلب تثبيت تحديث جديد إزالة النسخة القديمة أولًا؛ وهذا يمسح البيانات المحلية فقط، أما البيانات على Supabase فتبقى.

ملاحظات
-------
- مشروع Supabase المجاني يتوقف تلقائيًا إذا لم يُستخدم أسبوعًا كاملًا؛ ادخل لوحته واضغط Restore لإعادته، وبياناتك تبقى محفوظة.
- لتحديث التطبيق لاحقًا: أي تعديل على الملفات يبني نسخة جديدة تُثبَّت فوق القديمة دون حذف.
- التنبيهات تظهر داخل التطبيق أثناء استخدامه (إشعارات النظام خارج التطبيق غير مضمَّنة).
- تم حذف ملف keystore وكلمة مروره من هذه النسخة لتجنب كشف بيانات التوقيع.
